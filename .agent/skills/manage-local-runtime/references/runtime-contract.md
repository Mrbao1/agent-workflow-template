# Runtime Adapter Contract

Each adapter declares start command, readiness condition, public URL, required dependencies, bounded logs, test command, graceful stop, forced stop, cleanup verification and forbidden external effects.

Docker projects must start with `agent_` and record their absolute working directory and Compose files. Process adapters record PID, PGID, start time, command and cwd; a port record must reference its already registered owning PID and use loopback TCP. Identity mismatch fails closed. Registry writes use an exclusive lock and atomic replacement. Never delete volumes unless the requirement contract identifies disposable test data and exact targets.

Foreground review tools are not product adapters. They require an active orchestrator-observed member accepted by the complete shared `agent-team/v9` validator, an exact canonical review `role_type`, a valid payload/per-dispatch-envelope provenance chain, the role-appropriate review-chain/subject/predecessor bindings, a maximum 300-second timeout, an exact supervisor chain and an isolated process group recorded in `.agent/state/tool-leases.json`. Authorization rejects free-text role tricks, partial/legacy ledgers, non-content-addressed registration, registration-contract drift, stale envelopes, mixed review subjects, invalid predecessors, stale monitoring or progress, any permanent stall violation, interrupt/terminal state and expired deadlines; the positive integration fixture creates review and implementer owners through real `agentledger init/register` and proves that review-like implementer text grants no lease. The lease registry is separate from the node-6 runtime receipt so legitimate concurrent review does not invalidate product-runtime evidence. Process ancestry is derived from complete live `lsof` snapshots and is never accepted from caller-controlled environment variables. The wrapper removes the lease only after exact group termination; expired, orphaned or identity-mismatched leases fail closed and cleanup may terminate only their recorded group. Processes outside a valid lease remain baseline deltas.
