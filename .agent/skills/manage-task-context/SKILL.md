# Manage Task Context

1. Read `.agent/config.json`, `.agent/state/TASK.json`, `.agent/state/CONTEXT.json` and the bounded `.agent/state/EVIDENCE_INDEX.json` only; run `python3 .agent/scripts/contextctl.py check` and `python3 .agent/scripts/evidencectl.py verify --quiet` before trusting compacted state.
2. Enforce the active mode's byte, estimated Token, reference and child-agent limits.
3. Load one primary Skill. Load another Skill only for a concrete capability boundary.
4. Search references before reading; never bulk-load `.agent/skills`, assets or old evidence.
5. Never mutate `TASK.json` and then call a naked context transition. Canonical mutators call `contexttx.transition_task` with an operation profile; it locks TASK, binds exact before/after states and changed fields, commits TASK/side effects/context atomically, and rolls back on failure. `contextctl.py sync --transition` rejects callers without its fresh private authorization receipt.
6. Keep confirmed facts, decisions, changed files, evidence, P0/P1 risks and next action. Remove narration, repeated plans and resolved debate.
   During Node 1, `REQUIREMENT_CONTRACT.md` is a mutable non-authoritative draft and the capsule binds `unapproved-draft`, not transient bytes. The provider-approved transition atomically switches to the exact final contract SHA-256; from then on any byte change is drift.
7. For sub-agents, retain canonical identity, task, conclusion and evidence path—not chat history.
8. Run `contextctl.py check` and `workflowctl.py route-resume` before every continuation, after every child terminal event, after every compaction and immediately before every final reply. An age-expired capsule may use ordinary `sync` only when every integrity, TASK, contract, usage-freshness, size and budget binding is otherwise exact. Any actual drift stops work: use a bound transition when the TASK change is known; otherwise use `repair --reset --reason <cause> --summary <reconstruction> --source-tokens <estimate>`. Repair remains blocked until `approve-repair --source user:<decision> --human-decision-receipt <provider-receipt>` verifies a provider decision bound to the exact repaired capsule SHA-256. A route receipt with `terminal=false` forbids presenting the root task as complete.
9. Every checkpoint must include an `agent-context-usage/v1` estimate covering its own sequence and TASK invariant. A canonical TASK transition is not a compaction: its active-window estimate advances monotonically by `context.automatic_transition_token_increment[mode]` from the prior checkpoint. Ordinary `sync` can only preserve or increase that estimate. Only after a real host context compaction may `contextctl sync --host-compaction --source host:<event>` establish a strictly lower active-context baseline; record that compaction explicitly in its reason and summary. This is an auditable host declaration, not a provider-measured Token receipt. Keep the two accounts separate: cumulative TASK/provider Tokens continue to drive the total-cost gate, while only a provider receipt that explicitly measures the current active window may replace the active-window estimate (ordinary cumulative receipts do not). At soft watermark, stop optional references and new agents; at compact watermark, finish only the active atomic step, write the `agent-context-resume/v1` handoff and resume the exact node; at hard watermark, block implementation and split, escalate or request a decision. Loaded-reference reservations count toward the same watermark as task Tokens. Compaction never means completion.
10. Keep TASK hot state small with `workflowctl.py compact-state`: four recent rollback entries and eight recent failure signatures by default. Validate the complete hash-linked archive chain; recurrence gates use archived plus hot counts.
11. Inspect evidence with `evidencectl.py status`, preview with `compact --dry-run`, archive only old unreachable evidence, and verify with `verify --deep`. Referenced evidence stays active. `restore --archive <sha256>` must reproduce exact bytes and fail on collisions.

Read [budget-policy.md](references/budget-policy.md) when adjusting default budgets.
